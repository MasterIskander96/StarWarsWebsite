StarWarsWebsite 🌌

A Star Wars-themed console website built with Python that allows users to explore different features, play quizzes, and interact with the program.

📌 About the Project

StarWarsWebsite is a beginner-friendly Python programming project inspired by the Star Wars universe.

The website runs in the console and provides users with different functions, including Star Wars information, quizzes, registration, login, feedback, settings, and more.

🎮 Features

🌌 Star Wars-themed console interface
🌐 Official Star Wars Website

🔐 Login

📖 About the Website
💬 Feedback
⚙️ Settings
🔄 Interactive menu
🎲 Randomized features

🕹️ How to Use

Start the program.

Read the welcome message and available functions.

Enter the letter of the function you want to use.

Follow the instructions shown in the console.

Explore the different Star Wars Website features.

Use the menu to return to other functions.
