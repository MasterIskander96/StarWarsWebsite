StarWarsWebsite 🌌

A simple console website built with Python where users can explore Star Wars content, take quizzes, register accounts, and use various interactive features.

📌 About the Project

StarWarsWebsite is one of my Python programming projects inspired by the Star Wars universe.

The website provides different functions for Star Wars fans, including quizzes, registration, login, feedback, settings, and access to the official Star Wars website.
